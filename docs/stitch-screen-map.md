# Картография экранов Stitch: Проект FUSE

## Список найденных экранов Stitch

1. **Пульс (Refined) / Pulse Feed (Refined & Balanced) / Pulse Feed (Production Ready) / FUSE | Pulse Feed (Final)** - Вариации экрана основной видеоленты.
2. **Трек (UI REPAIR) / Трек (Final Repair) / Экран Track (Refined) / Track Screen (Refined & Balanced) / Track: 100 Day Build (Refined) / FUSE | Track Screen (Final)** - Вариации экрана трека (серии роликов).
3. **Миксер рекомендаций (UI REPAIR) / Миксер рекомендаций (Final Repair) / Algorithm Mixer (Refined & Balanced) / Algorithm Mixer (Simplified) / Algorithm Mixer (Refined) / FUSE | Algorithm Mixer (Final)** - Вариации экрана настроек алгоритмической ленты.
4. **Author Profile: Marina Arch / FUSE | Author Profile (Final)** - Профиль автора.
5. **World: Eco-Construction / FUSE | World Screen (Final)** - Экран Миров (тематических сообществ).
6. **FUSE Navigation Set** - Набор навигационных иконок.

## Детальный анализ ключевых экранов

### 1. Пульс (Основная видеолента)
- **Назначение:** Бесконечная вертикальная лента коротких видео с фокусом на иммерсивность и контент.
- **Ключевые компоненты:**
  - Полноэкранный контейнер видео.
  - Оверлей с информацией (название, автор, описание).
  - Скрытые/минималистичные контролы реакций (лайк, коммент, шеар).
  - Основной CTA ("Продолжить историю").
  - Кнопка вызова Миксера рекомендаций (иконка ползунков).
  - Нижняя навигационная панель.
- **Переходы:**
  - Свайп вверх/вниз - следующий/предыдущий ролик.
  - Тап по кнопке Миксера - открытие Bottom Sheet Миксера.
  - Тап по автору - переход в Профиль.
  - Тап по "Продолжить историю" - переход в Трек.
- **Динамические данные:** Видео-контент (URL), метаданные (название, автор, лайки, комментарии), статус "Продолжить историю" (связанный Трек).
- **Переиспользуемые элементы:** Нижняя навигация, бейджи, кнопки реакций.

### 2. Трек (Серия роликов/История)
- **Назначение:** Просмотр серии связанных видео (Трек), детальная информация о проекте/истории, эпизоды.
- **Ключевые компоненты:**
  - Обложка трека (компактная, не на весь экран).
  - Метаданные (название, автор, описание).
  - Индикатор прогресса (ProgressTimeline) по выпускам.
  - Вкладки (Выпуски, Материалы, Обсуждение, О проекте).
  - Список эпизодов (TrackEpisodeCard) с состояниями (просмотрен, текущий, будущий).
  - Основной CTA ("Смотреть следующий").
- **Переходы:**
  - Назад - возврат в Пульс на ту же позицию видео.
  - Тап по эпизоду - воспроизведение эпизода (переход в полноэкранный плеер или возврат в Пульс с новым контекстом).
- **Динамические данные:** Данные трека, список эпизодов, статус прохождения каждого эпизода, материалы.
- **Переиспользуемые элементы:** Карточки эпизодов, таймлайн прогресса, аватар автора.

### 3. Миксер рекомендаций
- **Назначение:** Тонкая настройка алгоритма рекомендаций пользователем. Открывается поверх Пульса.
- **Ключевые компоненты:**
  - Контейнер Bottom Sheet.
  - Переключатель режимов (Только люди, С помощью AI, Любой контент).
  - Слайдеры-весы (Знакомое-Новое, Развлечение-Польза, Локальное-Глобальное, Быстрое-Глубокое) (AlgorithmSlider).
  - Кнопка "Обновить ленту".
  - Кнопка сброса настроек.
- **Переходы:**
  - Свайп вниз или тап вне зоны - закрытие шторки.
  - Тап "Обновить ленту" - применение настроек (сортировка мок-данных), закрытие шторки, обновление ленты Пульса.
- **Динамические данные:** Текущие значения слайдеров, выбранный режим рекомендаций.
- **Переиспользуемые элементы:** Слайдеры настройки, переключатели (сегментированные контроли).

## Переиспользуемые элементы интерфейса (общие)
- **Нижняя навигация (BottomNavigation):** Общая для Пульс, Круг, Создать, Миры, Профиль.
- **Аватары (Avatar):** С круглой обводкой или без, разные размеры.
- **Бейджи (Badge):** "Proof Layer" бейджи, теги категорий, счетчики.
- **Кнопки (AppButton):** Primary с градиентом, Secondary ghost-style.
- **Иконки (AppIcon):** Единый пак, контурные/залитые состояния.
