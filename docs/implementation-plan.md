# План реализации прототипа FUSE

## Этап 1: Основа приложения и дизайн-система
- Инициализация проекта Expo (TypeScript, Expo Router).
- Настройка `eslint`, `prettier`.
- Создание структуры директорий (`src/components`, `src/features`, `src/design-system`, `src/data`, `src/types`, `src/hooks`, `src/store`).
- Реализация `src/design-system/tokens.ts` на основе `DESIGN.md` (цвета, типографика, отступы, радиусы, тени).
- Базовые переиспользуемые UI компоненты: `AppIcon`, `AppButton`, `Avatar`, `Badge`.
- Настройка глобальной тёмной темы.

## Этап 2: Mock-данные и локальное состояние
- Определение TypeScript интерфейсов (`Video`, `Track`, `Episode`, `User`, `MixerSettings`).
- Создание `src/data/mockData.ts` с русскоязычными реалистичными данными.
- Настройка локального стора (например, Zustand или React Context) для управления состоянием:
  - Список видео в Пульсе.
  - Текущие настройки Миксера (и логика сортировки/фильтрации мок-ленты).
  - Сохраненные реакции и подписки.

## Этап 3: Навигация и Основа
- Настройка Expo Router.
- Создание лейаута с нижней навигацией (`BottomNavigation`).
- Вкладки-заглушки: Круг, Создать, Миры, Профиль.
- Активная вкладка: Пульс.

## Этап 4: Экран «Пульс» (Видеолента)
- Интеграция `expo-video` и `FlashList`.
- Создание компонента `VideoFeedItem` (видео на весь экран, safe areas).
- Реализация логики воспроизведения (только активный ролик, пауза соседних).
- Оверлей метаданных и `VideoActions` в эргономичной зоне.
- Обработка жестов: одинарный тап (пауза), двойной тап (реакция), свайпы.
- Кнопка "Продолжить историю" (переход в Трек).
- Кнопка вызова Миксера.

## Этап 5: Миксер рекомендаций (Bottom Sheet)
- Реализация `AlgorithmMixerSheet` с использованием `@gorhom/bottom-sheet` (или самописного на Reanimated+GestureHandler).
- Разработка компонента `AlgorithmSlider` для 4 шкал.
- Переключатель режимов (Люди, AI, Любой).
- Связывание настроек с локальным стором для обновления ленты Пульса.

## Этап 6: Экран «Трек»
- Создание экрана детальной информации по треку.
- Передача `trackId` из Пульса.
- Компонент обложки и метаданных.
- Разработка `ProgressTimeline`.
- Разработка `TrackEpisodeCard` с разными визуальными состояниями (просмотрен, активен, заблокирован).
- Вкладки (заглушки для всех кроме "Выпуски").
- Логика "назад" (возврат к тому же индексу/состоянию плеера в Пульсе).

## Этап 7: Полировка и проверка
- Проверка доступности (зоны нажатий, контраст текста на видео).
- Анимации (Reduced Motion check).
- Проверка на Web, iOS, Android (если доступно, акцент на Web для превью).
- Typecheck, Lint.
- Обновление `README.md`.
